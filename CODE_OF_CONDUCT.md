# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
By participating (issues, discussions, pull requests, any project space) you agree to uphold it.

In short: be respectful and welcoming, assume good faith, give and accept constructive feedback, and focus on what is
best for the people who use SecretBroker. Harassment, insults and personal or political attacks are not acceptable.

## Reporting

Report unacceptable behaviour to the maintainers at **[CONTACT E-MAIL TO BE ADDED]**. All reports are reviewed
promptly and handled confidentially. Maintainers enforce the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
(correction, warning, temporary ban, permanent ban).

Security vulnerabilities are not conduct issues: report them as described in [SECURITY.md](SECURITY.md).
